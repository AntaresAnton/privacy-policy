# Privacy Policy

**Last Updated:** August 2026

This Privacy Policy applies to the TikTok API integration and application maintained by **AntaresAnton** ("the Application", "we", "us", or "our").

## 1. Information We Collect
When interacting with the TikTok API via our application, we may process:
- **Authentication Tokens:** OAuth 2.0 access and refresh tokens to securely interact with the TikTok API on behalf of authorized user accounts.
- **Account Details:** Basic profile identifiers (such as user ID, username, display name) strictly required for application functionality.
- **Content & Media:** Video files, descriptions, tags, and media assets provided by the user for publishing, uploading, or scheduling.

## 2. How We Use the Information
The collected information is used exclusively to:
- Authenticate and manage authorized sessions with TikTok API endpoints.
- Upload, schedule, and automate user-directed content to authorized TikTok accounts.
- Monitor video processing status and upload logs.

## 3. Data Sharing & Third-Party Disclosure
We **do not sell, rent, monetize, or share** any user data or credentials with third parties or external marketing platforms. Data is transmitted securely and directly to TikTok servers via official TikTok Developer APIs.

## 4. Data Storage and Security
All API credentials and access tokens are stored securely in local protected environments. We implement standard security practices to prevent unauthorized access, alteration, or disclosure of authentication data.

## 5. User Rights and Data Deletion
You can revoke access to this application at any time directly through your TikTok account security/authorized apps settings.

## 6. Compliance with TikTok Terms
Our application adheres to the [TikTok Terms of Service](https://www.tiktok.com/legal/page/row/terms-of-service/en) and [TikTok Developer Terms](https://developers.tiktok.com/terms/developer-terms-of-service).

## 7. Contact
For any questions regarding this Privacy Policy, please open an issue in this repository.
